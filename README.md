# .github

Organization-wide defaults for [Kyanite](https://github.com/kyanitecomputer).

GitHub applies the community-health files in this repository
(`CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, issue templates, and the
pull-request template) to **every** repository in the organization that does not
provide its own. Maintain them here once instead of per repo.

- `profile/README.md` — renders on the organization landing page.
- `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` — org-wide defaults.
- `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md` — default templates.

Per-repository concerns (CI workflows, `CODEOWNERS`, `dependabot.yml`) live in
each repository, not here.
